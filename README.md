# 声间 Sonara

从故事与情绪出发，让模型共同设计歌词、旋律、唱法和伴奏，再通过试听、局部修改和版本比较完成创作。当前重点是中文短段的自然感与共鸣。

**一个仓库、一个统一入口、五个功能空间。** 本仓库同时保存本机创作程序、网页展示版、进展文档和部署配置。

## 入口与能力

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 统一入口 | `/` | 选择创作空间，查看进展 |
| 故事与歌曲 | `/studio/` 或 `/compose.html` | 故事、情绪、词曲、演唱和局部修改 |
| 青春歌曲 | `/song/` 或 `/youth-song.html` | 《那条放学后的路》完整示范与段落情绪 |
| 声音与风格 | `/lab/` 或 `/sound-lab.html` | 句尾、声线、编配方向比较 |
| 按谱试唱 | `/score/` 或 `/score-trial.html` | 固定副歌的词谱与演唱实验 |
| 音轨工作台 | `/tools/` 或 `/audio-tools.html` | 导入、静音、独听、音量、裁剪与导出 |
| 项目进展 | `/progress.html` | 已实现能力、限制与下一步 |

短路径适用于发布包；本机可以直接访问对应 HTML 页面。各空间共用同一套源码，构建时也可选为独立站点首页。

## 本机运行

需要 Node.js 20.12+；网页与 Node 服务没有外部 npm 依赖。

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。源码可单独运行；新歌演唱还需要本机已有的 Python / DiffSinger、Ria 或绮萱声库、FluidSynth 与音色库。模型和声库未提交，不会自动下载。本机 Codex 需要已登录。服务仅监听回环地址，不直接开放公网。

`.local/` 包含本机生成作品和运行环境，`.env` 包含配置；均不纳入 Git。`validation/` 是本机验证证据，也不直接发布。原始 WAV 保留在本机；`published/` 仅含明确选定的示范作品与压缩试听副本。

## 网页部署

```sh
npm run build:site
```

输出 `build/site/`。它可以直接部署到静态托管平台，无需声库、密钥或本机账户。**远端展示版不会生成新歌或写入本机后台记录**；它提供示范试听、版本比较、乐谱查看，以及浏览器内的音轨编辑。不会假装远端生成成功。

一个仓库可构建六种站点入口：`portal`、`studio`、`song`、`lab`、`score`、`tools`，通过 `SONARA_SITE_TARGET` 选择。GitHub Pages 的子路径通过 `SONARA_BASE_PATH` 设置。具体配置与部署状态见 [部署说明](docs/deployment.md)。

试听下载为 MP3；无损母带和逐样本验证针对本机原始 WAV。生成过程中使用的声库、声码器、采样乐器各自保留原许可，本仓库不分发模型或音色库；见各页面声音来源说明。

## 验证与结构

```sh
npm run check
npm test
npm run build:site
```

| 目录 | 内容 |
| --- | --- |
| `dist/` | 网页源码、公开示例的乐谱和说明 |
| `server/` | 本机创作、歌声、项目、版本服务 |
| `scripts/` | 生成、渲染、验证与发布构建 |
| `published/` | 可审阅的远端示范素材与只读数据 |
| `deploy/` | 远端能力适配与部署配置 |
| `.github/workflows/` | 检查、站点构建与发布 |
| `tests/` | 行为、范围、音频与版本保留测试 |
| `docs/` | 定位、研究、能力边界和进展 |

真实音乐质量需要试听；自动测试和技术链路通过不等于作品成熟。六位参与者与一周回访的用户验证仍未完成。
