# 声间 Sonara

[打开统一入口](https://yydshly.github.io/sonara/) · [源码仓库](https://github.com/yydshly/sonara) · [当前进展](https://yydshly.github.io/sonara/progress.html)

从自己的故事与情绪出发，用 Codex 或 MiniMax 写歌词，确认后通过 MiniMax Code 生成音乐，再试听、反馈和保留版本。支持歌曲与纯音乐；原有按谱创作保留为独立实验。

**一个仓库、一个统一入口，完整的个人创作主线与独立实验空间。** 本仓库同时保存本机创作程序、网页展示版、进展文档和部署配置。

## 入口与能力

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 统一入口 | `/` | 选择创作空间，查看进展 |
| 我的音乐 | `/studio/` 或 `/studio.html` | 故事与情绪、歌词确认、MiniMax 任务、音频导入和版本试听 |
| 按谱创作实验 | `/compose.html` | 逐字词谱、演唱控制与局部修改实验 |
| 青春歌曲 | `/song/` 或 `/youth-song.html` | 《那条放学后的路》完整示范与段落情绪 |
| 声音与风格 | `/lab/` 或 `/sound-lab.html` | 句尾、声线、编配方向比较 |
| 按谱试唱 | `/score/` 或 `/score-trial.html` | 固定副歌的词谱与演唱实验 |
| 音轨工作台 | `/tools/` 或 `/audio-tools.html` | 导入、静音、独听、音量、裁剪与导出 |
| 项目进展 | `/progress.html` | 已实现能力、限制与下一步 |

短路径适用于发布包；本机可以直接访问对应 HTML 页面。各空间共用同一套源码，构建时也可选为独立站点首页。

## 本机运行

需要 Node.js 20.12+；网页与 Node 服务没有外部 npm 依赖。

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。新工作台的 Codex 歌词使用本机登录，MiniMax Code 安装和登录见[接入说明](docs/personal-music-studio.md)。MiniMax 路线不依赖本机歌声模型；原有按谱实验仍需要 Python / DiffSinger、Ria 或绮萱声库、FluidSynth 与音色库。模型和声库未提交，不会自动下载。本机 Codex 需要已登录。服务仅监听回环地址，不直接开放公网。

`.local/` 包含本机生成作品和运行环境，`.env` 包含配置；均不纳入 Git。`validation/` 是本机验证证据，也不直接发布。原始 WAV 保留在本机；`published/` 仅含明确选定的示范作品与压缩试听副本。

## 网页部署

```sh
npm run build:site
```

输出 `build/site/`。它可以直接部署到静态托管平台，无需声库、密钥或本机账户。**远端没有云端模型服务**；新工作台可以在当前浏览器保存创作资料、交接 MiniMax 任务、导入音频、试听比较和下载。公开示范、乐谱与音轨编辑继续可用。自动调用模型需使用本机版；不会假装远端生成成功。

一个仓库可构建六种站点入口：`portal`、`studio`、`song`、`lab`、`score`、`tools`，通过 `SONARA_SITE_TARGET` 选择。GitHub Pages 的子路径通过 `SONARA_BASE_PATH` 设置。具体配置与部署状态见 [部署说明](docs/deployment.md)。

试听下载为 MP3；无损母带和逐样本验证针对本机原始 WAV。生成过程中使用的声库、声码器、采样乐器各自保留原许可，本仓库不分发模型或音色库；见各页面声音来源说明。

## 验证与结构

```sh
npm run check
npm test
npm run build:site
```

| 目录 | 内容 |
| --- | --- |
| `dist/` | 网页源码、公开示例的乐谱和说明 |
| `server/` | 本机创作、歌声、项目、版本服务 |
| `scripts/` | 生成、渲染、验证与发布构建 |
| `published/` | 可审阅的远端示范素材与只读数据 |
| `deploy/` | 远端能力适配与部署配置 |
| `.github/workflows/` | 检查、站点构建与发布 |
| `tests/` | 行为、范围、音频与版本保留测试 |
| `docs/` | 定位、研究、能力边界和进展 |

真实音乐质量需要试听；自动测试和技术链路通过不等于作品成熟。六位参与者与一周回访的用户验证仍未完成。
