# 真实作品试听与评测

本轮把“优秀的产品效果”先落实为可重复的试听流程。页面右上角及左侧耳机图标进入「作品评测」。当前尚无真实演唱结果或人工音质评分；初始统计全部为零。

## 从哪开始

1. 使用自己的作品，或从评测页选择八份原创歌词之一。选择样例会创建独立项目、带入歌词和声音设置，不会自动提交生成。
2. 在创作室生成或导入真实音频。生成需先按 [连接说明](generation-setup.md) 配置服务；也可导入通过其他工具制作的歌曲或纯音乐。
3. 完整试听当前 B 版本的评测范围。若当前是 A 基准，请先切回 B，避免听与记不是同一个版本。
4. 打开「评测当前版本」，按听感填写各项评分、具体问题、来源、尝试轮次、时间与费用。
5. 保存后查看结论；后续可从记录恢复相同的版本设置，回听并与新版本比较。现有调整会保留。

## 分开评价歌曲与纯音乐

歌曲评六项：歌词准确、发音咬字、节奏断句、旋律编曲、人声表现、音频质量。生成歌曲核对的是生成时提交的歌词，后续草稿不作为旧音频的唱词依据；导入歌曲核对其版本中的歌词草稿。

纯音乐评旋律编曲和音频质量，不填写唱词评分，也不计入中英文歌曲达标数。试听时仍应记录是否出现意外人声、杂音、突兀衔接或不自然的结束。

评分含义：1 明显不可用，2 问题较多，3 仍需修改，4 愿意保留，5 非常满意。适用项均至少 4 分才显示「本次试听通过」；歌曲还必须有参考歌词并完成逐句核对。未核对、低分结果均可保存。一次人工试听通过不代表服务整体通过验证。

请填写具体观察，例如「00:18 第二句漏了一个字」「副歌更有力量，但主唱被鼓盖住」。如果有人工补词、外部混音或重新制作，在观察中一并记录。费用未知时留空，不以零元代替未知；币种可选人民币或美元。

## 版本、记录与限制

- 记录保存当时的歌词、生成来源、音轨设置、局部效果与裁剪范围。之后修改项目不会更改已有记录。
- 原音频仍在本机项目素材中。JSON 导出包含设置快照，CSV 包含评分与观察；两者都不打包音频文件，不能单独恢复声音。重要作品请同时导出音频。
- 恢复快照前会检查音频素材是否仍在此浏览器；缺失时明确提示，不把其他版本当成原评测音频。
- 完整试听与真实创作确认由填写者负责，系统不自动识别唱词或音质。内置器乐示例不能进入评测，测试音不可勾选为真实创作结果。
- 每个候选先控制在三轮尝试内，保存不满意的结果。八份标准歌词只是一组比较材料，不代表不同语言、风格和长度已被充分覆盖。
- 页面统计的是评测记录次数，不是独立用户人数，也不是八份题目覆盖率。真实用户验证另在「验证记录」页面执行。

现阶段先验证歌词演唱与纯音乐。配音生成、自动分轨和精确局部重唱尚未接入，不在本页冒充已验证能力。
