# 音乐方向、速度与声线

这轮解决的是听感节奏拖沓，以及个人作品只能使用同一套编配的问题。原整曲示范为 82 BPM，早期新作品被限制在 72–104 BPM；所有新歌曾使用一套简易合成伴奏。原整曲不覆盖，新能力进入个人创作流程。

## 已接入的流程

1. 新建作品时填写想法、情绪起点与终点，选择音乐方向、72–144 的整数 BPM，以及 Ria / 绮萱声线。
2. 风格和精确速度一起传给词曲模型。歌词支持每句 6–14 个汉字，新增四分之三拍，鼓励快风格采用短音符和有变化的节奏。模型返回不同速度会失败，不默默改成另一速度。
3. 先准备器乐旋律试听和采样伴奏。用户确认后才演唱。
4. 已有四句作品在“调整速度、风格与声线”里可另存改编版本。原歌词、音高、和弦和音符拍数保持；改变 BPM 会重新计算实际时间并重新演唱。选择新声库也会重新演唱全部四句。
5. 只更换编配且 BPM、声线相同时，直接复用完成版的人声文件，导出后检查逐字节一致。歌词或旋律的单句修改仍保留其他三句。
6. 不同速度的 A/B 在同一音乐拍位置切换；已听完则从头比较。可导出人声、伴奏、混音、歌词、旋律 MIDI、伴奏多轨 MIDI、乐谱 JSON 和乐器事件 JSON。

## 四种方向

| 方向 | 默认速度 | 乐器与节奏 | 创作意图 |
| --- | --- | --- | --- |
| 校园民谣 | 100 BPM | 钢弦吉他分解与扫弦、木贝斯、轻打击乐 | 亲近、自在的讲述 |
| 复古律动 | 116 BPM | 电钢琴切分、清音吉他、律动贝斯与鼓组 | 怀念里继续向前 |
| 轻快流行摇滚 | 132 BPM | 电吉他强拍与八分节奏、电贝斯、强鼓组 | 明亮、有冲劲 |
| 温暖抒情 | 88 BPM | 钢琴、后半进入的弦乐、轻鼓与低音 | 从克制走向展开 |

默认速度可调整。风格影响模型写词与旋律的要求、实际 MIDI 乐器、节奏型、声部进入及渲染，绝非只替换页面标签。四种编配目前是人工编写的可复用规则，根据项目和弦及速度渲染；不是能自由生成任何风格的编曲模型。

## 真实验证

使用同一套产品接口，创作《追上来》：周五下班骑车见老朋友，从惦记没做完的工作，到听见朋友喊名字、笑着追上去。词曲由已连接的 Codex 生成，主版本为绮萱、132 BPM 流行摇滚。再保留歌词、旋律及拍数，分别以 100 / 116 / 88 BPM 重新演唱并编配。另验证同速换伴奏复用原声，以及同速换 Ria 的独立新演唱。

首页和示范作品页提供四版真实声音。为了便于比较，试听卡使用同词同旋律；新建作品会根据所选风格重新写词曲。

记录位于 `validation/music-style-run.json`；最终音频检查位于 `validation/music-style-audio-check.json`。验证脚本检查输出时长、44.1 kHz / PCM24、峰值、混音组成、音符与元音入口对齐、MIDI 速度、声线实际模型日志、只换伴奏时的人声一致性、原整曲完整性。单元测试另检查设置冻结、请求去重、取消与原版保留、确认稿绑定、版本继承，以及无法证明保留内容时拒绝发布成功。

技术验证不代表好听，也不代替用户判断歌词是否有共鸣、声音是否自然、情绪是否成立。未生成任何假的用户评分。

## 当前边界与后续

- 个人自由创作仍是四句中文、八小节、C 大调和受限音域。英文、任意完整歌曲、爵士／说唱等独立节奏语法没有在本轮冒充支持。
- Ria 和绮萱都属于 DiffSinger；更换声线不是自然度已经达标。短音符也可能暴露咬字、衔接问题，应继续通过真实试听筛选。
- 情绪目标影响模型写词和旋律，但本轮没有把每种风格强行映射到气声、张力旋钮。两种声库支持的声学输入不同，绮萱不具有 Ria 的独立张力输入。
- 使用已有的本机声库、FluidSynth 和 GeneralUser GS，不新增付费调用或外部音频上传。相关模型及音色库保留各自许可，社区声码器当前用于非商业本机验证。
- 下一轮应先选出值得继续打磨的短样，改善演唱连贯性和乐器质感，再扩展为有主副歌发展的 60–90 秒作品。
