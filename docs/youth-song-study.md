# 原创样本：那条放学后的路

创作方向来自用户：有经典老歌气质的新原创歌曲，以 90 后的青春为样本。此稿由本次对话写出歌词、旋律及编配，再使用已有的本机歌声合成能力演唱。入口 `/youth-song.html`，工作台首页也提供试听入口。

## 作品设定

歌名《那条放学后的路》，副题「给长大后的我们」。以一部分 90 后在 2000 年代至 2010 年代初的校园记忆为切口，不将某一种校园经历当作所有人的共同经历。

情绪从当年的舍不得回家，经过长大后的各自奔忙，最后落在对彼此的祝愿。人物关系保持开放：故事里的“你”可以是同桌、好友，也可以是没说出口的喜欢。核心画面是两个人共享耳机、故意慢走的放学路；年代线索服务于故事，没有堆砌品牌与流行名词。

声音目标为温暖、克制的慢板华语流行。第一稿 82 BPM，4/4 拍，C 大调，旋律音域 A3–A4；62 小节、26 句演唱，文件 185 秒，包含自然收尾。整曲有前奏、两轮主歌与预副歌、副歌、桥段、末副歌和尾奏。

## 词曲与编配决定

- 主歌用较低音区与短音叙事，从窗台、刘海、耳机进入；第二主歌沿用旋律，内容换成停用的号码、箱底的同学录和加班夜。
- 两段预副歌用同一旋律连接「那时以为夏天很长」和「后来才懂那段时光」，相同的音乐对应认知变化。
- 副歌开头 E4–G4–A4–G4–E4–D4–E4，先上扬再回落，句尾长音给“路”留出空间；第二句在 G 上停留，第四句回到 C。
- 木吉他分解和弦与钢琴贯穿，主歌一主要留给歌词；预副歌引入鼓与弦乐，副歌展开，桥段抽掉鼓，末副歌恢复完整编配。编配均为程序合成乐器的小样，尚非真实乐器录音。
- 演唱按逐字拼音、音高与时长合成，段落调整电平，加入轻量空间效果；没有使用某位歌手的录音或声音克隆。现有声线只能验证曲子唱起来的基本效果，不能保证达到所设定的成熟演唱气质。

完整歌词见 `dist/youth-song/lyrics.txt`。逐字乐谱、段落与和弦见 `score.json`，旋律 MIDI 为 `melody.mid`。页面显示各段创作意图，可逐句定位，也可查看音符与拍数。

## 制作流程与产物

1. `scripts/create-youth-song.py score` 写出专门创作的结构化词曲。
2. `arrange` 根据段落与和弦生成钢琴、木吉他、贝斯、鼓、弦乐五轨，以及伴奏和旋律示范。
3. `sing` 通过本机 DiffSinger / Ria 逐句合成，再混合生成整曲；同一句可缓存，缓存必须与实际发音及音高控制输入匹配。
4. WAV 为 44.1 kHz / 24 bit；网页提供 192 kbps MP3 试听与下载。独立人声为干声，歌曲混音含空间效果；切换模式保持同一时间位置。

音频与导出文件位于 `dist/youth-song/`，私有推理缓存位于 `.local/youth-song/phrases/`，渲染记录在 `.local/youth-song-render.log`。`result.json` 仅在整曲成功写出后发布，包含时长、耗时、峰值和文件散列。

本次没有调用在线整曲生成服务。原有四句创作与修改入口保留约束，尚未扩展为自由整曲编辑；此样本证明一份明确写出的完整词曲可以进入现有歌声合成流程。

## 试听后再决定的事项

先检查副歌能否留下印象，以及「那条路」和成年后的生活是否能引起共鸣。随后分别判断旋律、歌词断句、咬字、音色、情绪、编配层次。优先修改具体听到的问题，不把文件成功生成视为质量通过。

本次不预填主观评分，不计入六人用户研究。下一轮应保留当前第一稿，依据用户试听反馈选择具体段落修改；是否扩展整曲生成和编辑，以完整作品的实际听感为依据。
