# 从故事到可修改的演唱

2026-09-27：已接入现有创作工作台，当前范围是中文四句短段。技术链路通过不等于听感、共鸣或完整歌曲能力已通过。

## 用户如何驱动

从一段经历、一个具体细节，以及开始和结束时的感受出发。可以提到喜欢某首歌带来的感受，但不需要提供参考歌曲；模型不得沿用现成歌词、旋律或特定录音。情绪目标保存在作品及每个版本中。

“根据故事选择节奏、风格和声线”默认开启。取消勾选即可指定已有音乐方向、速度与声线。用户只需说故事和感受，不必写音符或逐字演唱参数。

同一次模型创作输出歌词、每句意图、旋律音符、真实停顿、连音、逐字气声与咬字速度，以及实际伴奏音符。页面显示情绪走向；逐句唱法与配器理由按需展开。先读词、听器乐草稿，确认后生成演唱。

## 实际执行与可控范围

- 新入口使用 `expressive-v1`。保留旧项目的格式与 API 默认行为，不重写已存在的音频。
- 四句可分别占一至三个小节，不再强制每句两小节。一字可有一至三个连音，MIDI 不重复写连音歌词；时长依情绪和语义决定，没有统一短尾规则。
- 伴奏由模型为本次作品写出二至四个乐器声部的实际音符，本机采样乐器按谱播放，未套入旧风格循环。
- 模型选择的声线必须已安装。音高、时长、重叠、音节对应、伴奏范围、控制值等均先校验，再合成。
- 逐字气声与咬字控制验证实际进入声学模型。张力通过音区、节奏、和声、留白及配器设计表达，不宣称模型提供了通用情绪旋钮。
- 修改分为唱法、歌词、旋律音高、词句与断句。修改稿必须经过精确版本确认，再生成新版演唱。原版保留，可 A/B 比较或回到原版继续。
- 只改唱法时，保留原音素时长、音高、其他演唱曲线，只替换气声与咬字控制。先撤销旧控制再施加新设置，连续修改不会叠加失控。
- 只重唱所选句；其他句的实际 PCM 音频直接复用，伴奏文件保持一致。尚未支持在新格式上随意替换整首编配，界面不展示旧的循环编配入口。

## 本轮真实案例

故事为共同讨论的虚构示例：年轻时忙工作，将陪伴推给以后；搬家时翻到旧日历，圈着未成行的旅行。模型生成《日历里的海》，102 BPM、28 秒，使用 Ria、本机 DiffSinger 和电钢琴、贝斯采样。

初稿四句：日子稳了搬家翻出旧日历 / 圈着去海边那天我又加班 / 总说以后才懂你等得多累 / 愿你已看过那片海。

这些句子属于待试听的模型初稿，不是人工评审通过的优秀歌词。模型选择前三句各三小节、末句两小节；41 个字对应 43 个音符，含两处连音。伴奏为 37 个电钢琴音符、17 个贝斯音符。

## 下一步的质量判断

先听这段词是否顺、旋律是否自然、第三句是否唱出领悟、最后一句是否有余味。按具体反馈逐句修改；不要把这次示例的速度、句长、音色或少拖音固定为其他故事的模板。通过不同故事和情绪的重复创作后，再扩展主歌、副歌与整曲结构。英文、配音和完整歌曲仍是后续范围。
