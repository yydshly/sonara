# 从想法到词曲与演唱

入口：工作台顶部「从想法创作」，或 `/compose.html`。

## 已实现的流程

输入中文创作想法 → Codex 输出歌名、歌词、逐字拼音、音高、时值与和弦 → 本机校验 → 生成 MIDI 和器乐旋律试听 → 用户确认 → 本机 DiffSinger / Ria 演唱 → 保存混音、独立人声和词曲。

使用者不需要先写好歌词或乐谱。初版为四句中文短歌，每句 6–10 个汉字、两小节；4/4 拍，72–104 BPM、C 大调、G3–G4 范围。每个字对应一个音符，七拍演唱加首尾各半拍换气。结构约束用于让当前声库可靠接收输入，不代表最优作曲方法或成品质量保证。

词曲、节奏与和弦由实际模型调用产生；伴奏使用项目程序按和弦生成的电钢琴、贝斯与鼓，尚非模型自由编曲。旋律试听明确标注无演唱，只有声学合成完成后才显示演唱选项。新生成歌曲可直接在本页继续逐句修改，无需进入固定副歌试验页。

## 可控修改与版本

完成演唱后，在「打磨当前版本」选择一句，说明想改什么。当前支持两种互斥的修改：

| 修改类型 | 允许改变 | 程序保留 |
| --- | --- | --- |
| 歌词 · 保留旋律 | 选中一句的等字数歌词、逐字发音 | 音高控制曲线、音符与时长、伴奏、其余三句音频 |
| 音高 · 保留歌词与节奏 | 选中一句的音高 | 歌词、发音输入、音符时长、伴奏、其余三句音频 |

Codex 仅返回这句的歌词与拼音，或音高列表。服务端将变更应用于原版快照，拒绝越界字段、无实际变化和不满足乐谱约束的结果。原始完整乐谱不会交给模型任意覆盖。

修改稿会展示要求、实际前后差异和保留范围。此时只有旋律示范；改词尚未变成新演唱。用户确认的版本摘要必须与服务端一致，才能启动局部演唱。每次只合成选中一句，直接复制其余音频和伴奏；导出后逐样本核对未修改区间，不通过则不发布成功。

A/B 切换保留播放位置；音频、歌词、MIDI 与乐谱下载均对应正在试听的版本。版本按同一作品归组，记录来源，可以打开任意已完成旧版继续并另存新版本。每份修改稿独立保留；输入中的修改要求按基础版本暂存，刷新后仍可恢复。

保留音高控制输入不等于实际演唱音准、咬字和自然度获得保证，仍需要试听判断。当前不支持变字数、改变节奏、重新编配、任意录音局部重唱或多句同时修改。后续应根据真实试听失败案例决定放开哪些约束，而非一次放开全部生成能力。

## Codex 接入

采用官方 [`codex exec` 非交互调用](https://learn.chatgpt.com/docs/developer-commands#codex-exec)，通过 `--output-schema` 指定 JSON 输出形状，`--output-last-message` 接收最终结果。实际本机已安装 CLI，并通过 `codex login status` 确认已使用 ChatGPT 账户登录。

- 服务端通过参数数组启动 CLI，想法经标准输入传递，不拼接为命令。客户端无法指定可执行文件、工作目录或模型参数。
- 每次任务使用独立的工作目录、只读权限和临时会话；不加载用户配置。关闭命令执行、连接器、插件、浏览器、图像生成与子代理入口。应用只解析结构化词曲，不执行模型返回的代码。
- 不读取、复制或向网页暴露登录凭据。想法会发送给 Codex；网页在提交前说明使用已登录账户的额度。本机歌声合成不上传音频。
- 未设置模型覆盖时，使用 CLI 默认模型。需要本机明确配置时可在启动服务的环境中设置 `SONARA_CODEX_MODEL` 或 `SONARA_CODEX_BIN`；不能由网页请求覆盖。
- 本机运行用户必须可以访问自己的正常 Codex 运行目录。受限执行环境若禁止写入 Codex 状态目录，会失败且留下失败记录；不复制认证文件或绕过权限来解决。

连接采用本机个人试验方式，未实现公网多用户认证、账户隔离或商业部署。服务仅监听本机，保留同源写入保护。生产接入需要另行设计服务端账户、配额、费用与访问控制。

## 保存与失败处理

`.local/compositions/<任务 ID>/` 保存想法、模型原始输出、经校验的乐谱、MIDI、歌词、旋律试听，以及完成后的歌声与混音。诊断记录只保存在私有服务目录，不提供网页下载。

任务初次落盘完成后才调用模型；重复提交同一个请求不重复调用。词曲草稿与演唱是两步，生成草稿不会自动演唱。取消后的迟到结果不发布，失败结果不冒充成功；重新演唱只重新运行本机声学流程，不再次请求 Codex。重启服务会将未完成任务标记为中断，不自动重新调用模型。已有完成作品保持可用。

模型输出需满足逐字数量、音高范围、拍数、和弦和拼音校验。不能通过时明确失败，不偷偷替换成固定演示词曲。自动检查只能验证结构与文件，不能判定歌词、旋律或演唱优秀。

## 实际尝试（2026-09-26）

| 想法 | 实际生成作品 | 词曲特征 | 实际音频 |
| --- | --- | --- | --- |
| 夜归末班车、便利店暖灯、重新期待生活 | 暖灯把明天照亮 | 84 BPM，四句各七字、28 个音符 | 25 秒演唱；本机合成约 44.87 秒 |
| 雨后骑车去海边，长短句自然变化，重新获得自由 | 骑向海风 | 96 BPM，7/8/7/8 字、30 个音符 | 22 秒演唱，本机合成 33.14 秒；通过网页提交想法并确认合成 |

两次 Codex 词曲阶段分别约 55 秒和 52 秒，包括本机校验和伴奏准备；设备、网络与模型负载会影响时间。原始结果分别位于 `4aaf3017-3715-4a91-944b-e6710200a8a6` 和 `9d11313a-01ac-4988-8a16-2d49369f4481` 目录。先前因 Codex 状态目录写入受限而失败的一次记录也保留，没有作为成功案例。

使用 Ria / 狸安声库，作者 RibosomeK；配套声码器的非商业许可限制仍适用，详见 [歌声试作与组件授权](score-to-song-trial.md)。两次试验未记为真实用户研究或质量通过结论。

《骑向海风》已通过网页完成两轮局部修改：V2 将第三句改为「海风吹起白衣角」，V3 在此基础上调整第四句两个音高。每轮都先查看修改稿、再确认演唱，分别用时 14.43 秒和 12.25 秒；各自只改变对应的 5 秒，区间外音频逐样本一致。实际文件、版本 ID 和核对数据见 [交付检查记录](verification.md)。
