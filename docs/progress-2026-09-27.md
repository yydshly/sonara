# 阶段进展 · 2026-09-27

## 目标与判断标准

帮助有故事、歌词或声音素材的人创作符合情绪、自然且有共鸣的作品。效果优先，其次是局部可控、操作清楚和效率。当前以中文短段反复验证，不用界面完整或生成成功代替音乐质量。

## 已完成

1. 浏览器音轨工作台：导入、音量、静音、独听、非破坏性裁剪、版本比较和 WAV 导出。自动分轨未接入。
2. 按谱试唱：固定中文副歌、歌词与 MIDI、等字数改词、本机合成和局部音频保留。
3. 完整青春样本：《那条放学后的路》，约 185 秒，包含词、谱、配器、歌声、分轨与段落情绪设计。
4. 音乐方向与声线试验：四种编配方向、两种本机声线；对咬字、拖音与句尾进行了迭代。
5. 自由创作主线：故事/情绪输入，模型联合设计词曲、停顿、连音、唱法和实际伴奏音符；先确认草稿再生成歌声。
6. 可控局部修改：歌词、音高、词句与断句、气声与咬字四种范围，精确版本确认，原版保留，A/B 与导出。
7. 产品整理：统一首页，五个功能空间，公开进展页；本机功能与远端展示的能力分开标识。

## 当前作品与证据

| 作品 | 结果 | 判断边界 |
| --- | --- | --- |
| 靠窗那边 | 少拖音 V2 得到用户“现在可以”的反馈 | 只认可这个片段，不固定成通用模式 |
| 日历里的海 | 模型从故事生成 28 秒，词、曲、唱法与伴奏可追溯 | 还没有用户听感验收 |
| 日历里的海 V3 | 基于 V1 只调整第三句气声与咬字，其他演唱曲线锁定 | 原始 WAV 区间之外逐样本一致，MP3 仅供远端试听 |
| 那条放学后的路 | 完整专门创作样本、多种编配对照 | 不代表自由创作整曲的可重复能力 |

本机案例 ID、原始音频验证与范围说明见 [情绪驱动创作](emotion-driven-creation.md)。网页发布只导出选定示范，不导出账户、模型运行日志、用户听感记录或全部本机作品。

## 仍需完成

- 不同故事、情绪、速度和声区下的自然感与共鸣验证。
- 跨主歌、副歌、过渡的原创整曲创作与局部一致性。
- 英文演唱、旁白配音、自动分轨和专业混音母带。
- 远端模型计算服务、账户与用户隔离、配额、任务队列和云端作品保存。
- 六位真实参与者及一周自愿回访；现有技术试验不能计入这些门槛。

## 部署结构

所有功能在一个 Git 仓库维护。统一首页链接五个功能空间；每个空间也有独立访问路径与独立构建入口。静态发布包提供已完成作品试听，后台创作仍依赖本机。部署地址与平台状态以 [部署说明](deployment.md) 为准。
