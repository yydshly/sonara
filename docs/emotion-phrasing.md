# 让情绪落实到乐句与演唱

产品目标是创作符合表达意图、值得反复听的音乐。情绪贴合与音乐成立分别判断；可播放、无削波、字段合格都不是艺术质量结论。

## 这一轮可以完成的过程

1. 在青春样本中保存作品目标和每个段落的情绪、故事、歌词、音乐、演唱要求。
2. 选择整首或一个有歌词的段落，优先打磨自然讲述、记忆点或情绪变化。
3. 选择保留歌词打磨唱法、歌词与唱法一起打磨，或只调整节奏。Codex 读取保存的依据、全曲歌词、原谱和本轮反馈，输出逐句表达提案：字句与发音、时值与留白、重点词，以及逐字气声、发声张力和元音过渡参数。
4. 先核对新旧歌词和修改理由；器乐 A/B 仅预览节奏，不能预览改词、气声或唱法。歌词的要求是具体动作、人物关系与没说出口的话，避免用情绪标签、年代符号和口号代替共鸣。
5. 确认这一份乐谱后，由本机 DiffSinger 重新演唱发生变化的句子。整曲、干声与逐字乐谱可对照，A/B 切换保留位置。
6. 对对应版本记录“情绪是否更贴合”“音乐表达是否更自然”，附具体时间和理由。所有结果初始为未评价，用户可以判断变差或无法确定。

## 创作与保护范围

所有模式保留逐字音高、和声、伴奏、速度与结构。默认锁定歌词与发音；明确选择“歌词与唱法一起打磨”后，只允许选定范围等字数改词和对应发音，标题句仍锁定。时值与留白限定在原有两小节句长内。新演唱在独立版本保存，不覆盖原录音。没有变化的句子与句外区域保留原始音频。每份方案从原作开始，暂不叠加之前的表达或混音版本。

模型给出的意图不是效果保证。用更长时值突出某个词，可能也造成拖沓；缩短虚词可能变得含混。当前 Ria 声库支持气声与发声张力曲线偏移（本轮限于 ±1.5 dB、0.5 dB 步长），以及元音过渡倍率（0.9–1.1、0.05 步长）。控制围绕逐字音符中心平滑，仅在有声区域应用；没有把故事张力曲线直接换算成声学参数。参数进入声学模型后合成新演唱，不是对成品音频简单调音量或均衡。

仍不能切换歌手、直接添加真实换气、自由指定滑音或保证情感真实性。这里的“气声”是发声特征，不能等同于吸气声。当前仍使用 Ria / 狸安试验声库和程序伴奏，组件的非商业边界沿用 [词曲试唱说明](score-to-song-trial.md)。未开展商用授权核验或发行验收。

## 情绪与音乐怎样一起判断

| 维度 | 试听要回答的问题 | 可以落到的创作动作 |
| --- | --- | --- |
| 情绪与叙事 | 这一句表达的是亲近、怀念还是祝愿？是否与前后段落相连？ | 调整词义、叙事位置、停顿、唱法与编配 |
| 旋律与记忆点 | 能否记住标题句？重复是否形成认知而非单调？ | 动机变化、音高走向、句长与重复位置 |
| 节奏与可唱性 | 词组是否被拆散？重音是否落得自然？长句是否赶？ | 逐字时值、连断、起句与收句留白 |
| 张力与结构 | 情绪在哪里积累、展开、回落？是否一直一样用力？ | 和声、音区、节奏密度、配器与动态的配合 |
| 人声与制作 | 词是否清楚？音准、句尾是否自然？伴奏是否遮盖表达？ | 发音、演唱、声部设计、音量与空间 |

这些是创作问题，不是统一评分公式。当前实做等字数改词、逐字节奏与留白、气声与发声张力、元音过渡；自由改旋律、重新编配等动作仍需扩展。不同类别按作品目标调整重点：叙事歌曲关注字句与故事，舞曲关注律动与段落能量，氛围音乐关注音色、空间与渐变；不要求每一种音乐都具备强副歌或同样的起伏。

## 实现与可追溯性

`codex exec` 采用结构化输出、本机已有登录和受限只读执行环境，模型不得使用工具；做法参见 [Codex 非交互使用文档](https://developers.openai.com/codex/noninteractive)。服务端再次检查字段、逐字数量、时值、句长和范围，不能仅凭模型声称“已保留”放行。

每份草稿冻结作品依据、原谱、本轮反馈、改词许可和输入文件校验值；演唱确认绑定包含演唱参数的新谱校验值。原素材改变则拒绝沿用。处理可以取消，刷新可恢复状态，重启中断不会自动重新提交。服务同时核对参数范围、发音字典、音高保护、控制曲线变化和实际声学输入，记录逐句执行证据。只有完整音频通过文件格式、时长、峰值和范围外一致性检查后，才暴露成功音频。歌词导出及页面定位歌词跟随所选音频版本。

`.local/song-phrasing/<版本 ID>/` 保存草稿、新谱、MIDI、器乐对照、音频和记录；模型调用发送目标文字、歌词与谱，不发送音频。网页只公开明确的作品资产，不公开模型日志、目录或登录信息。创作记录与音频分别下载，尚无完整工程打包。

六人真实创作研究与一周回访仍待执行；技术验证不计作听众的质量认可。
