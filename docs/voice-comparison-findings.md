# 第二个本机声库：同词同谱对照

2026-09-26。已生成真实音频；听感结论仍待用户试听。

## 已完成

- A：狸安 Ria（RibosomeK），沿用已经修正的元音落拍方式。
- B：绮萱 Qixuan v2.7.0（颜绮萱、YQ之神及制作组），使用其独立的时长、音高、气声/发声模型与指定的 PC-NSF-HiFiGAN 2025.02 声码器。
- 两者均为 DiffSinger AI 歌声合成。这是两套声库与演唱模型链的比较，不是两个不同引擎家族的比较，也不是在完全相同演唱细节上只换音色。
- 模型来自作者官方发布页；绮萱约 401 MB、配套声码器约 50 MB，下载后分别通过发布页 SHA256 校验。全部推理在本机完成，未发送歌词或音频到音乐服务。

主歌选“风把试卷吹过窗台 / 粉笔灰落满你刘海”；副歌选“那条放学后的路 / 怎么走也走不够”。每段 11.71 秒音乐，加 1 秒尾音空间；每个声库共演唱四句。

两者均使用相同歌词、82 BPM、相同节奏和音程关系。为避开 Ria 公布音域上沿之外的原副歌 A4，统一由 C 大调降两个半音至降 B 大调后重新演唱。本次音符范围 G3–G4；不声称该音域是绮萱的最佳声区，后续仍需按听感检查。

两段各生成一个相同的钢琴伴奏，使用本机 FluidSynth 与 GeneralUser GS。人声以线性增益对齐至 -23 LUFS 目标；未使用压缩器掩盖动态。先听干声，再听同一钢琴下的演唱。原作品、咬字修正版和三种编配草稿均保留。

## 技术证据

`dist/youth-song/voice-comparison-v1/result.json` 记录源文件散列、两套模型身份、歌词与音符、音高曲线散列、音频文件散列和响度增益。

生成过程校验了：

- 两个声库的对照乐谱完全一致，模型身份不同；每个音符的元音入口与乐谱一致。
- 输出为 44.1 kHz / 24 bit；无非有限值、无削波；时长一致。
- 各版混音减去各自干声，均还原同一钢琴伴奏（在 PCM24 量化误差范围内）。
- 原始歌词、乐谱、人声、伴奏、整曲和 S1 整曲的散列未改变。

网页在同一位置切换 A/B，片段听完后再选另一声库会从头播放。主播放器与对照播放器互斥播放；对照片段不冒充整首歌曲的新版本。

本次首次运行 A 共约 63 秒，B 共约 127 秒，包含加载、词典解析与渲染。两次运行存在部分重叠，且 B 首次使用了较慢的词典解析，不能据此评判模型速度。已经改用安全的 C 词典解析器；音频与逐句结果缓存可复用。

## 产品上得到的约束

绮萱配置支持气声、发声强度、发音速度和音色偏移，但没有 Ria 的独立发声张力输入。后续应建立声库能力表，让可见控制与真实模型输入一致，不能把同一组参数无差别套到所有声音上。本次没有将绮萱接入任意想法创作、整曲重唱或表情编辑，因此原有自由创作仍使用 Ria。

试听时分开判断：咬字清楚吗，连贯吗，长音稳吗，是否像在表达这段故事。不同音色本身不等于更高质量。本轮仍未验证英文、完整歌曲、反复局部修改或多风格自动演唱。
