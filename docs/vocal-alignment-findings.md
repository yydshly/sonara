# 演唱咬字与落拍校正 · 2026-09-26

用户已认可曲调，反馈演唱像不善音律的人。本次保持词曲与伴奏，检查实际合成输入后修正音素分组，并完成首段副歌 A/B。

## 已确认的问题

旧合成器把每个字的声母、介音、元音和韵尾全部分配到该字音符内。DiffSinger 的时长模型需要按发声锚点分组：开头辅音放入前一时间组，元音（部分辅音＋介音＋元音组合从介音开始）落在音符起点。

依据：[OpenUtau 官方音素器 ProcessWord / ProcessPart](https://github.com/stakira/OpenUtau/blob/master/OpenUtau.Core/DiffSinger/DiffSingerBasePhonemizer.cs)。[Ria 作者说明](https://github.com/RibosomeK/RiaDiffSinger)也提醒，某些辅音、介音和长音韵尾的时长需要调整。

实际缓存中的“那条放学后的路”最后一个字：

| 控制输入 | 原版 | 校正后 |
| --- | ---: | ---: |
| `l` 时长 | 1.463 秒 | 0.071 秒 |
| `uw` 时长 | 0.732 秒 | 2.195 秒 |
| 元音相对乐句起点 | 4.756 秒 | 3.293 秒 |
| 乐谱中“路”的起点 | 3.293 秒 | 3.293 秒 |

这确认了元音落拍延迟与字头被拉长的问题，不代表所有听感问题均由它造成。没有把所有音高拉成直线，也没有添加统一的颤音或气声。

## 验证和限制

- 完成真实本机模型合成，四句约 41.6 秒；这不是生成性能承诺。
- 导出后逐样本验证：副歌之外音频完全一致，原歌词、谱面、伴奏及源音频散列保持不变。
- 前三句人声 RMS 与原版一致；第四句为保留峰值余量低约 0.51 dB。不是严格的感知响度盲测。
- 对齐边界、元音起音、字典异常、已有表达控制与区域保留测试通过。
- 试听记录绑定音频散列；缺失、篡改或来源变化的对比不能被记录为有效版本。
- 主观音质尚未验收。重点听字头是否干净、元音是否准时、连贯性是否改善、长音是否自然。
- 声库作者公布音域为 A2–G#4；样本副歌含 A4，超出其公布上限一个半音。这是后续音色/声区匹配的独立风险，本次按保留曲调的要求未改调或换声库。
