# 真实歌曲生成：连接与验收

本轮增加了可调用的 ElevenLabs 音乐接口适配，作为第一项待评测候选。没有配置密钥，也没有执行真实生成、扣费或音质评分。配音和自动分轨暂未接入。

## 连接方式

1. 在 `sonara` 目录中将 `.env.example` 复制为 `.env`，在本机填写 `ELEVENLABS_API_KEY`。不把密钥填入网页或聊天。
2. 使用 Node.js 20.12 或更新版本重新启动 `npm run dev`。
3. 打开工作台的“连接状态”。“已配置”只说明本机读到了密钥，不保证账户权限、余额或音质已验证。
4. 点击“生成演唱”，确认本次歌词、声音方向、时长和人声感觉。提交前会说明内容发送到 ElevenLabs，并使用该账户的生成额度。先用 30 或 60 秒的短任务验证。

接口适配按 2026-09-26 查阅的[官方生成文档](https://elevenlabs.io/docs/api-reference/music/compose)和[创作计划文档](https://elevenlabs.io/docs/eleven-api/guides/how-to/music/composition-plans)实现。默认候选模型是 `music_v2_5`，可通过 `SONARA_MUSIC_MODEL=music_v2` 更换为受支持的另一版本。正式选择以实际评测为准。

目前提供三组明确的声音方向。项目中的中文故事保留作创作参考，不假装已自动翻译成精确音乐控制。提交的歌词可以编辑，用 `[主歌]`、`[副歌]` 或 `[Verse]`、`[Chorus]` 分段。30 秒短样只应提交少量歌词；过长的歌词可能唱不完，需试听检查。

纯音乐模式不提交隐藏的歌词，使用服务的纯器乐开关。它仍需检查是否出现意外人声。新生成不承诺延续旧版旋律或音色，也没有把全曲重生成描述为精确局部修改。

## 生成任务与作品版本

- 每次提交在本机持久保存任务后，再向服务发送一次请求。相同请求编号重复提交会返回同一任务。
- 本机逐项处理任务，最多允许三项排队/运行。失败、超时、刷新或重启都不会自动再次生成。
- 已经发送的请求即使停止等待，也可能由供应商继续处理或计费。中断任务需要先核查供应商账户，不能以本机取消推断未扣费。
- 收到音频后先显示候选结果，可以试听、下载服务返回的原始 MP3，再选择“加入作品”。此前的版本保留。
- 每个新版本保留生成时的歌词快照。后续改词显示“尚未生成对应音频”。提交歌词与实际唱词是否一致，需要人工试听核对。
- 段落位置来自生成计划，并非识别得到的逐字时间戳。

## 保存与音质

项目及加入作品的音频存于浏览器 IndexedDB；任务与服务原始结果存于 `sonara/.local/generations`。两个位置均在本机，但备份方式不同。清理浏览器不会自动删除服务目录，删除服务目录也不会自动清理浏览器。服务仅监听 `127.0.0.1`，只对本机工作台开放，不是可直接公开部署的多用户后台。

`.env` 与 `.local` 被 Git 忽略，不在网页公开文件目录中。当前没有云同步、账户或跨设备恢复。

新增音频导入保存原始文件。WAV 编辑副本尽量沿用文件采样率；其他格式建立 48 kHz 编辑副本。混合不同采样率音轨时使用浏览器的离线重采样，播放和输出使用正确的采样率。编辑结果导出 24 bit 立体声 WAV；这不会把有损来源变成真正无损来源。旧版已转换为 22.05 kHz 的素材无法自动恢复，应重新导入原文件。

监听音量不改变导出。普通峰值保持不变；检测到实际过载时提示降低音轨电平，并阻止把已削波的编辑结果作为正常 WAV 导出。原始文件仍可直接下载。

内置浏览器下载的完成事件仍无法稳定确认，因此增加“保存到本机文件夹”。原文件与编辑 WAV 可直接保存到 `sonara/.local/exports`，页面返回实际路径。这一路径已通过浏览器导入、保存与磁盘校验；原文件 SHA-256 保持一致。

## 第一轮评测材料

`evaluation/music-cases.json` 包含 8 组原创歌词，中文、英文各 4 组，覆盖短句、重复、数字、结构与长篇连贯性。`results` 初始为空；它不包含生成音频。

工作台已提供「作品评测」页面，可从这些样例创建项目，或评测自己的真实歌曲 / 纯音乐。试听记录独立保存在浏览器，保留当时的版本快照；不会写回题库的 `results`。操作方法与评分含义见 [真实作品评测](quality-review-guide.md)。目前真实记录仍为空。

每个候选对同一任务最多尝试三轮。记录所有结果的任务编号、供应商/模型、源歌词、实际唱词问题、评分、选中与否、保留要求、用时和总费用。费用以供应商实际记录为准，本机没有伪造的费用估计。先完成短样，再验证完整歌曲；保留盲听结果后决定是否继续采用这一候选。

自动测试中的服务成功响应为明确标注的合成传输数据，只测试任务和文件管道，不能证明声音真实、音质合格或供应商可用。真实音质评测需要连接账户后完成。
